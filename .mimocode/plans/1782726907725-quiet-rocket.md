# Lua Script Center - 企业级重构计划

## 目标

将现有的分散 Lua 脚本管理重构为统一的 Lua Script Center，实现：
- 统一注册中心 + SHA预热
- Actuator 端点暴露脚本状态
- 补全缺失脚本（秒杀、令牌桶、锁获取）
- 修复内联 Lua 问题（QuotaEnforcer）
- 统一分布式锁（Aspect 使用 Lua）

### Step 4: 新增 Lua 脚本

#### 4a. `lock/acquire.lua` - 分布式锁获取
```lua
-- 原子性获取分布式锁
-- KEYS[1] = lock key
-- ARGV[1] = lock value (owner token)
-- ARGV[2] = TTL in milliseconds
-- Returns: 1 if acquired, 0 otherwise

if redis.call('EXISTS', KEYS[1]) == 0 then
    redis.call('SET', KEYS[1], ARGV[1], 'PX', ARGV[2])
    return 1
end
return 0
```

#### 4b. `inventory/seckill.lua` - 秒杀防超卖
```lua
-- 原子性秒杀扣减：检查+扣减+防重复
-- KEYS[1] = stock key
-- KEYS[2] = user purchased key (防重复下单)
-- ARGV[1] = quantity
-- ARGV[2] = user id
-- ARGV[3] = expire seconds (防重复key过期时间)
-- Returns: 1=成功, -1=库存不存在, -2=库存不足, -3=已购买过

-- 检查是否已购买
if redis.call('EXISTS', KEYS[2]) == 1 then
    return -3
end

local stock = redis.call('GET', KEYS[1])
if not stock then
    return -1
end
if tonumber(stock) < tonumber(ARGV[1]) then
    return -2
end

redis.call('DECRBY', KEYS[1], ARGV[1])
redis.call('SET', KEYS[2], '1', 'EX', ARGV[3])
return 1
```

#### 4c. `rate-limit/token_bucket.lua` - 令牌桶
```lua
-- 令牌桶限流
-- KEYS[1] = bucket key
-- ARGV[1] = max tokens (桶容量)
-- ARGV[2] = refill rate (每秒补充令牌数)
-- ARGV[3] = now (当前时间戳，秒)
-- ARGV[4] = requested tokens
-- Returns: 1=允许, 0=拒绝

local key = KEYS[1]
local max_tokens = tonumber(ARGV[1])
local refill_rate = tonumber(ARGV[2])
local now = tonumber(ARGV[3])
local requested = tonumber(ARGV[4])

local bucket = redis.call('HMGET', key, 'tokens', 'last_refill')
local tokens = tonumber(bucket[1]) or max_tokens
local last_refill = tonumber(bucket[2]) or now

-- 补充令牌
local elapsed = now - last_refill
local refill = elapsed * refill_rate
tokens = math.min(max_tokens, tokens + refill)

if tokens >= requested then
    tokens = tokens - requested
    redis.call('HMSET', key, 'tokens', tokens, 'last_refill', now)
    redis.call('EXPIRE', key, math.ceil(max_tokens / refill_rate) * 2)
    return 1
else
    redis.call('HMSET', key, 'tokens', tokens, 'last_refill', now)
    redis.call('EXPIRE', key, math.ceil(max_tokens / refill_rate) * 2)
    return 0
end
```

### Step 7: 重写 sliding_window.lua 为真滑动窗口

**文件**: `scm-common/cache/src/main/resources/lua/rate-limit/sliding_window.lua`

当前是固定窗口（INCR + EXPIRE），改为真滑动窗口（Sorted Set）：

```lua
-- 滑动窗口限流（基于 Sorted Set）
-- KEYS[1] = rate limit key
-- ARGV[1] = max requests per window
-- ARGV[2] = window size in milliseconds
-- ARGV[3] = current timestamp in milliseconds
-- ARGV[4] = unique request id (e.g. UUID)
-- Returns: 1=允许, 0=拒绝

local key = KEYS[1]
local limit = tonumber(ARGV[1])
local window = tonumber(ARGV[2])
local now = tonumber(ARGV[3])
local request_id = ARGV[4]

-- 移除窗口外的过期请求
local window_start = now - window
redis.call('ZREMRANGEBYSCORE', key, '-inf', window_start)

-- 获取当前窗口内的请求数
local count = redis.call('ZCARD', key)

if count < limit then
    -- 允许：添加当前请求
    redis.call('ZADD', key, now, request_id)
    -- 设置 key 过期时间为窗口大小（毫秒转秒）
    redis.call('PEXPIRE', key, window)
    return 1
else
    -- 拒绝
    return 0
end
```

同时更新 `RateLimitFilter.java` 调用方式，传入当前时间戳和唯一请求ID。
