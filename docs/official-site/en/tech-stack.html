technology choices

A choice is
an answer to a
problem.

Versions come from the parent POM, each service POM and scm-web/package.json. Reasons come from the boundaries actually used in code. This is not a logo wall; it says why each choice exists and what it does not solve.

Java 21 Spring Boot 4.1.2 Spring Cloud 2025.1.4 Spring Cloud Alibaba 2025.1.0.0 Next.js 16.4.3 PostgreSQL 18 Redis 8 ClickHouse 26.10
01

Runtime & framework

Twenty-six services share one runtime and one version policy. Upgrades happen together; debugging does not start with “which stack is this?”.

Java 2121

One runtime; records, pattern matching and the standard concurrency library. Hot-path performance comes from Redis Lua and async orchestration, not from a thread model.

Spring Boot4.1.2

Web, validation, Actuator and auto-configuration in one baseline. The parent POM owns versions; services declare only what they use.

Spring Cloud2025.1.4

Foundation for gateway, configuration and discovery. Services register with Nacos; the gateway routes by service name.

Spring Cloud Alibaba2025.1.0.0

Nacos 3.2.4 as discovery and configuration; Seata and Sentinel join through the same ecosystem instead of a self-built control plane.

Apache Dubbo3.3.6

Internal synchronous calls use RPC contracts; interfaces and DTOs live in each module's api/. Browsers still use REST through the gateway, never RPC.

Jakarta Servlet6.x

Only jakarta.servlet; maven-enforcer rejects javax.servlet so Boot 4 cannot inherit a silent incompatibility.

02

Data & storage

Each store has one role: ledger, speed, analysis, retrieval, files. Crossing roles shows up immediately as a consistency or latency cost.

PostgreSQL18

One db_* per service. ord_order, inv_reservation and sup_purchase_order are partitioned monthly and kept 24 months. No cross-database JOIN.

MyBatis-Plus3.5.17

Explicit SQL is easier to audit and tune. The tenant predicate is injected by an interceptor; soft delete is a global deleted field.

Redis8

Lua handles deduction, restock and flash sale; reservation index and short-TTL cache. The two-level cache (Caffeine L1 + Redis L2) is off unless a service opts in.

ClickHouse26.10

Analysis only: ODS → DWD → DWS → ADS, ordered by tenant_id and partitioned by toYYYYMM. It never sits on the transaction path.

Elasticsearch9.5.5

Product search, similar products and recommendations; single/batch indexing and full rebuild. It is not a ledger; the index can be rebuilt.

Kafkacp-kafka 8.4.0

Event backbone with at-least-once delivery and idempotent consumers. Serialization uses JacksonJsonSerializer, never the removed JsonSerializer.

RabbitMQ5.37.0 client

Reliable queues; RabbitAdmin declares queues at startup. Kafka carries event streams, RabbitMQ carries point-to-point delivery.

MinIO / S3client

Object storage compatible with S3/OSS. Downloads use 30-minute presigned URLs; metadata stays in PostgreSQL.

Flyway13.11.1

One version line per service; validate-on-migrate=true, out-of-order=false. Boot 4 moved auto-configuration into a starter — see the limits below.

03

Consistency & scheduling

Strong consistency only inside an aggregate. Cross-service consistency is designed compensation, not a framework wish.

Seata2.0.0 client

AT mode for cross-service transactions; every database needs undo_log. Order and inventory reservations also have explicit TCC confirm/cancel branches.

Sagain-house

A lightweight Saga orchestrator in scm-common/integration for long-running compensation; no separate orchestration engine.

XXL-Job3.5.0

Scheduled work: expired reservation release, stock snapshots, tenant fee calculation. An empty admin address refuses to start, so it never “looks like it is running”.

FlowableBPMN

Approval engine; the platform exposes start, approve, reject, pending tasks and process status, while process models are defined in BPMN.

04

Observability

Metrics, traces and logs are not three systems. They are three views of the same request.

Sentinel2025.0.0.0

Circuit breaking and rate limiting; rules can come from Nacos. It is a stability boundary, not an optional plugin.

SkyWalkingagent 9.3.0

Distributed tracing; OAP and UI use the 10.4.0 image. A cross-service call shows both the Dubbo and HTTP segments.

Micrometer + Prometheus1.17.2

Metric collection. Each service exposes Actuator endpoints; Prometheus scrapes and Grafana displays.

ActuatorBoot 4

/actuator/health is the shared health endpoint. The tenant filter excludes it; otherwise probes would be rejected.

05

Frontend

The target stack is decided; the migration is still running. New pages enter shadcn/ui only; legacy Ant Design pages are replaced domain by domain.

Next.js16.4.3

App Router. proxy.ts handles locale prefixes and redirects unauthenticated users. Next 16 renamed the middleware convention to proxy.

React19.3.1

The dashboard is a client-rendered page aggregating gateway data directly; the old server-side prefetch could not forward auth and tenant cookies.

TypeScript7 + 6

typecheck runs TypeScript 7 via @typescript/native; ESLint and the Next build still use TS 6 because typescript-eslint does not yet support the TS 7 API.

Tailwind CSS4.3.3

CSS-first configuration. design-tokens.css is the single palette source for Ant Design, Tailwind and canvas charts.

shadcn/uivendored

Component source lives in src/components/ui and is editable. No second CSS-in-JS layer.

Ant Design6.6.7

Legacy pages only. No new AntD pages: when a domain migrates, its AntD dependency goes with it.

TanStack Query5.104.5

Server state with a single QueryClient. Query data is never wrapped in 'use cache'; caching policy is explicit at the Query layer.

TanStack Table / AG Grid9.3.1 / 36.2

TanStack Table is the default. AG Grid enters only through the lazy DataGrid wrapper, keeping heavy grids out of the first paint.

Zustand5.0.16

UI state only (sidebar, theme, filter context). Server data never enters the store.

React Hook Form + Zod7.91 / 4.6

Long forms use zodResolver and a shared FormField; validation rules mirror backend constraints.

Recharts / ECharts / G63.10 / 6.1 / 5.1

Recharts for KPIs, ECharts for complex figures, G6 for topology. All lazy-loaded; ECharts imports only echarts/core.

Vitest + Playwright5.0.5 / 1.64.1

Vitest for data transforms and pure logic; Playwright for core ledger paths across Chromium, Firefox and WebKit.

06

Delivery & verification

Build and release are not the last step. They decide whether every earlier choice can be verified.

Maven multi-module3.9.x

There is no root pom.xml. Every command needs -f com.scm.parent/pom.xml; modules reference ../scm-*.

GitHub ActionsCI

PRs run backend test-compile test and frontend typecheck/lint/test/build; pushes run verify and upload to Codecov.

Docker Composeinfra

The default profile starts Nacos, PostgreSQL, Redis, Kafka, RabbitMQ, Elasticsearch and ClickHouse; core services run as JVM processes.

SonarCloudoptional

Runs only when SONAR_ORG is set. An external quality platform is not a hard gate.

OWASP Dependency Checkadvisory

continue-on-error: dependency findings are reported, but they do not decide for the team whether a release is blocked.

JaCoCooff by default

The parent POM sets jacoco.skip=true; coverage gates run only with -Djacoco.skip=false.

07

Boundaries & capabilities left off

A stack table that only lists “what we use” hides what is not actually running. Here is the current state.

Read-write split
@Master/@Slave annotations and auto-configuration exist, but the whole capability is gated on spring.datasource.rw.enabled=true. No service enables it today; single-database reads and writes are the default.
Optional subsystems
The OAuth2 authorization server (security.uaa.enabled) is enabled only in scm-auth; mTLS, PKCE, two-level cache and data sync are off by default and require an explicit opt-in.
Flyway auto-config
Boot 4 moved Flyway auto-configuration into spring-boot-starter-flyway; only scm-supplier declares it today. Services with just flyway-core may not run migrations automatically.
Integration tests
Tests tagged @Tag("integration") are excluded by surefire; CI never boots a Spring context and runs Mockito units plus frontend gates. Docker/Testcontainers verification must be enabled locally.
Canal / ShardingSphere
Neither is in the running path: the Canal client dependency is commented out in the parent POM, and ShardingSphere is not a dependency. Search sync is handled by scm-search's index endpoints; database sharding is not enabled.
Frontend migration
Ant Design 6 still appears on legacy pages; new pages use shadcn/ui only. Migration is per domain, without a one-time-rewrite milestone.
Commerce tests
payment and promotion have unit tests; member, mall and search have thinner coverage. “It has endpoints” is not the same as “it has been verified”.
