Three differences

Not feature count — boundary quality
01

Isolation begins at the request, not in a config file

The tenant id is resolved at the front of the filter chain and written into the thread context. A MyBatis interceptor then appends the predicate to every SELECT, UPDATE and DELETE. Async work inherits the same context through a dedicated executor. Missing tenancy is rejected by default; a service may switch SQL isolation off, but the boundary never disappears silently.

chain TenantFilterTenantContextHolderTenantInterceptorAsyncTenantAutoConfiguration
02

The hot path trusts memory, not a round trip

Stock deduction, restock and flash-sale counters run in Redis Lua; the hot path never queries PostgreSQL. Reservations last 900 seconds by default, convert to a real deduction after payment, and release on cancel or timeout. Alerts and daily snapshots have their own endpoints and never sit in front of the order path.

scripts deduct_stock.luaadd_stock.luaseckill.lua·900s
03

Nothing is written before it is proven

Payment callbacks are verified before a payment changes: RSA2 for Alipay; signature header and AES-GCM resource decryption for WeChat Pay v3; merchant id, channel and amount must match the local payment. Audit writes only accept internal HMAC-SHA256 signed requests, and there is no HTTP delete endpoint.

03

Recent hardening

Make boundaries verifiable, not pages
SRM

Enterprise supplier profile

Admission review, certificate validity, risk level, cooperation state, scorecard and change log converge on one profile; expiring certificates have their own query.

DOCUMENT

Versions and trail

Templates support version increments, publish-and-archive and variable schemas; documents expose version lists, sign/archive transitions and an audit trail for each action.

PAYMENT

Callback verification

Alipay RSA2 and WeChat Pay v3 signature/decryption; merchant, channel and amount are cross-checked; missing keys reject the callback, duplicates are idempotent.

ORDER

Pagination and state machine

Order center and fulfillment gained pagination and @Valid; order status only moves along the enum's legal paths, and terminal states stay terminal.

FINANCE

Service fees and reconciliation

Platform service fee bills expose pending lists and payment registration; reconciliation records support reconcile, confirm and difference marking on the same row.

INVENTORY

Alerts and snapshots

Stock alerts support scanning, statistics and resolution; daily snapshots support trend queries, and a repeat run for the same day skips existing rows.
