Three critical paths

Request · transaction · evidence

A tenant request

Tenant → SQL
01

Resolve the tenant

The client sends X-Tenant-Id (or Tenant-Id, or the tenantId query parameter).

02

Enter the context

TenantFilter runs at HIGHEST_PRECEDENCE + 10 and writes to TenantContextHolder. If it is missing and scm.tenant.required=true, a TenantParseException is raised.

03

Authenticate and authorize

After JWT validation, ApiAccessControlFilter resolves URL permissions through scm-system. If the lookup fails, the request is denied.

04

Rewrite SQL

TenantInterceptor appends an alias-qualified tenant_id predicate to SELECT, UPDATE and DELETE. Statements without a FROM table are skipped rather than failed.

05

Propagate and clear

@Async work uses tenantAwareTaskExecutor to inherit the tenant. The request clears the ThreadLocal in a finally block.

An order and its fulfillment

Order → Fulfillment
01

Create the order

scm-order creates it in PENDING_PAYMENT. Every status change goes through the aggregate's transitionTo().

02

Reserve stock

Redis Lua atomically decrements available quantity and writes the reservation index, defaulting to 900 seconds. Seata TCC provides confirm/cancel branches for order and inventory.

03

Payment callback

After signature verification the payment becomes paid; the order enters PAID and the reservation converts to a real deduction. Duplicate callbacks are no-ops.

04

Fulfillment

Pick → pack → ship (waybill and carrier recorded) → sign off. The order follows PENDING_SHIP → SHIPPED → IN_TRANSIT → DELIVERED → COMPLETED.

05

Cancel or timeout

The reservation is released. An order can only move to CANCELLED from PENDING_PAYMENT or PAID; terminal states stay terminal.

An audit write

Signed · Append-only
01

Collect

@AuditLog is intercepted by the shared SysAuditLogAspect, which builds the record. Unannotated methods produce no record.

02

Deliver

SysAuditServiceClient sends through RestClient, forwarding X-Tenant-Id and the caller's JWT.

03

Sign

The interceptor generates HMAC-SHA256 headers over timestamp + nonce + appId + uri + sortedParams.

04

Guard

AuditWriteRequestGuard only admits signed POST /sys-audit-log calls inside a 5-minute window. The controller exposes no delete route.

05

Mirror high risk

Records with risk level ≥ 3 are mirrored into sys_sensitive_operation_log. Without a userId the mirror is skipped, but the main record is never lost.

The two speeds of data

Transactions exact · analysis fast
OLTP / Hot path

Transactions and the hot path

Stock is promised at order time while the ledger stays in PostgreSQL. The two paths have explicit roles and never wait on each other.

  • PostgreSQL 18one db_* per service
  • Partitioned tablesord_order · inv_reservation · sup_purchase_order
  • Partition retention24 months
  • Redis 8Lua deduct · restock · flash sale
  • Stock reservation900-second timeout
  • Read-write splitoff by default, explicitly enabled
OLAP / Cold path

Analysis and the cold path

Reports do not press on the order database. Events enter Kafka first, then land in ClickHouse's layered models.

  • Kafkacp-kafka 8.4.0 event backbone
  • ClickHouse 26.10ODS → DWD → DWS → ADS
  • Sort keytenant_id first
  • RetentionODS 1y · DWD 2y · DWS/ADS 3y
  • Elasticsearch 9.5.5product search and rebuilds
  • MinIOobject storage · 30-minute presigned URLs
04

Runtime constraints

Values that hold in the code
Tenant required
On by default. Requests without a tenant are rejected; excluded paths are /actuator/** and /v3/api-docs/**.
SQL isolation
Predicates on SELECT / UPDATE / DELETE. A service can switch it off with scm.tenant.sql-isolation=false; INSERT relies on the audit field handler.
Permission failure
Deny, not allow. A failed URL permission lookup raises AccessDeniedException, so business APIs are fail-closed.
Audit write
HMAC-SHA256 with a 5-minute window. Only internal callers pass the guard; there is no HTTP delete and queries are read-only.
Payment callback
Unconfigured means rejected. WeChat v3 enforces a 5-minute clock window; Alipay checks app_id and seller_id; amount and channel must match the local payment.
Stock reservation
900 seconds. Payment confirmation converts it; cancel or timeout releases it; an expired release endpoint feeds the scheduler.
Data retention
Audit 2 years · login 1 year · API logs 90 days · notifications 6 months · order events 3 years. Partitioned tables default to 24 months.
File access
30-minute presigned URLs. File metadata and object storage are separate; download URLs are not long-lived.
Integration tests
Skipped by default. Tests tagged @Tag("integration") are excluded by surefire; CI runs unit tests and the frontend gates.
