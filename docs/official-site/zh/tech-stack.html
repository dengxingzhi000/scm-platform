01

运行时与框架

26 个服务共享一套运行时与版本管理。统一的代价是升级要一起做，收益是排障时不用先问“这是哪个栈”。

Java 2121

统一运行时；使用 record、模式匹配与标准并发库。热路径性能来自 Redis Lua 与异步编排，不依赖线程模型。

Spring Boot4.1.2

统一 Web、Validation、Actuator 与自动配置；父 POM 管理全部版本，服务只声明自己需要的能力。

Spring Cloud2025.1.4

网关、配置与发现的基础版本；服务通过 Nacos 注册，网关按服务名路由。

Spring Cloud Alibaba2025.1.0.0

Nacos 3.2.4 作为发现与配置中心；Seata 与 Sentinel 通过同一生态接入，减少自建控制面。

Apache Dubbo3.3.6

内部同步调用走 RPC 契约，接口与 DTO 放在各模块的 api/；浏览器侧仍走 REST + 网关，不让前端感知 RPC。

Jakarta Servlet6.x

只用 jakarta.servlet；maven-enforcer 禁止 javax.servlet，避免在 Boot 4 上出现隐式不兼容。

02

数据与存储

每种存储只承担一种角色：账本、速度、分析、检索、文件。跨界使用会立刻在一致性或性能上付出代价。

PostgreSQL18

每个服务独立 db_*；ord_order、inv_reservation、sup_purchase_order 按月分区，默认保留 24 个月。不做跨库 JOIN。

MyBatis-Plus3.5.17

显式 SQL 便于审计与优化；租户谓词由拦截器统一追加。软删除是全局字段（deleted）。

Redis8

Lua 负责扣减、回补与秒杀；预占索引与短 TTL 缓存。两级缓存（Caffeine L1 + Redis L2）默认关闭，由服务按需开启。

ClickHouse26.10

分析层专用：ODS → DWD → DWS → ADS，按 tenant_id 排序、toYYYYMM 分区；不在交易路径上。

Elasticsearch9.5.5

商品搜索、相似商品与推荐；支持单条／批量索引与全量重建。它不是账本，索引可以重建。

Kafkacp-kafka 8.4.0

事件主干；至少一次投递，消费者用幂等处理重复。序列化使用 JacksonJsonSerializer，不用已移除的 JsonSerializer。

RabbitMQ5.37.0 client

可靠队列；RabbitAdmin 启动时声明队列。与 Kafka 分工：RabbitMQ 负责点对点可靠投递，Kafka 负责事件流。

MinIO / S3client

文件对象存储，兼容 S3／OSS；下载走 30 分钟预签名地址，元数据留在 PostgreSQL。

Flyway13.11.1

每服务独立版本线；validate-on-migrate=true、out-of-order=false。Spring Boot 4 把自动配置拆到 starter，见下方边界。

03

一致性与调度

强一致只发生在聚合内部；跨服务的一致性是设计出来的补偿，不是框架许愿。

Seata2.0.0 client

AT 模式用于跨服务事务；每个库都要有 undo_log。订单与库存的预占另有 TCC 分支，显式 confirm／cancel。

Sagain-house

scm-common/integration 提供轻量 Saga 编排；用于长流程补偿，不引入独立编排引擎。

XXL-Job3.5.0

定时任务：过期预占释放、库存快照、租户服务费计算等；空 admin 地址会拒绝启动，避免“看起来在跑”。

FlowableBPMN

审批流程引擎；平台提供发起、通过、驳回、待办与流程状态接口，流程模型由 BPMN 定义。

04

可观测

指标、链路与日志不是三套系统，而是同一个请求的三种视角。

Sentinel2025.0.0.0

熔断与限流；规则可来自 Nacos。默认不是“可选插件”，而是网关与业务服务的稳定性边界。

SkyWalkingagent 9.3.0

链路追踪；OAP 与 UI 使用 10.4.0 镜像。跨服务调用在 trace 里能看到 Dubbo 与 HTTP 两段。

Micrometer + Prometheus1.17.2

指标采集；每个服务暴露 Actuator 端点，Prometheus 抓取，Grafana 展示。

ActuatorBoot 4

/actuator/health 是统一健康端点；租户过滤器把它排除在租户校验之外，否则探针会被拒绝。

05

前端

目标栈已经确定，迁移仍在进行。新页面只进 shadcn/ui，存量 Ant Design 页面按域替换。

Next.js16.4.3

App Router；proxy.ts 负责 locale 前缀与未登录跳转。Next 16 把 middleware 约定改名为 proxy。

React19.3.1

仪表盘是客户端页面，直接聚合网关数据；不再用服务端 prefetch 去赌 cookie 转发。

TypeScript7 + 6

typecheck 走 TypeScript 7（@typescript/native）；ESLint 与 Next 构建仍走 TS 6，因为 typescript-eslint 尚未支持 TS 7 API。

Tailwind CSS4.3.3

CSS-first 配置；design-tokens.css 是 Ant Design、Tailwind 与 Canvas 图表的唯一调色板来源。

shadcn/uivendored

组件源码直接进 src/components/ui，可改；不引入第二套 CSS-in-JS。

Ant Design6.6.7

只保留在存量页面；不新增 AntD 页面。迁移完成一个域，就删掉一个域的 AntD 依赖。

TanStack Query5.104.5

服务端状态；一个 QueryClient。查询数据不包 'use cache'，缓存策略在 Query 层显式配置。

TanStack Table / AG Grid9.3.1 / 36.2

默认表格用 TanStack Table；AG Grid 只通过懒加载的 DataGrid 包装进入，避免把重表格打进首屏。

Zustand5.0.16

只放 UI 状态（侧栏、主题、筛选上下文）；服务端数据不进 store。

React Hook Form + Zod7.91 / 4.6

长表单使用 zodResolver 与统一 FormField；校验规则与后端约束保持一致。

Recharts / ECharts / G63.10 / 6.1 / 5.1

KPI 用 Recharts，复杂图形用 ECharts，拓扑用 G6；全部懒加载，ECharts 只从 echarts/core 引入。

Vitest + Playwright5.0.5 / 1.64.1

数据转换与纯逻辑走 Vitest；核心账本路径走 Playwright（Chromium / Firefox / WebKit）。

06

交付与验证

构建与发布不是“最后一步”。它决定了前面所有选择能否被验证。

Maven 多模块3.9.x

根目录没有 pom.xml；所有命令都要 -f com.scm.parent/pom.xml，模块通过 ../scm-* 引用。

GitHub ActionsCI

PR 跑后端 test-compile test 与前端 typecheck／lint／test／build；push 跑 verify 并上传 Codecov。

Docker Composeinfra

默认 profile 起 Nacos、PostgreSQL、Redis、Kafka、RabbitMQ、Elasticsearch、ClickHouse 等；核心服务以 JVM 进程运行。

SonarCloudoptional

仅在 SONAR_ORG 设置时运行；不把外部质量平台设为硬门禁。

OWASP Dependency Checkadvisory

continue-on-error：发现依赖漏洞会报，但不会替开发者决定是否阻塞发布。

JaCoCooff by default

父 POM 设置 jacoco.skip=true；只有显式传 -Djacoco.skip=false 才执行覆盖率门禁。

07

边界与未启用项

选型表如果只写“用了什么”，会掩盖“其实没跑起来”的部分。下面这些是当前状态。

读写分离
@Master／@Slave 注解与自动配置存在，但整套能力由 spring.datasource.rw.enabled=true 控制；当前没有服务启用，默认单库读写。
可选子系统
OAuth2 授权服务器（security.uaa.enabled）仅在 scm-auth 开启；mTLS、PKCE、两级缓存、数据同步默认关闭，需要服务显式 opt-in。
Flyway 自动配置
Spring Boot 4 把 Flyway 自动配置拆到 spring-boot-starter-flyway；当前只有 scm-supplier 显式引入。只声明 flyway-core 的服务，迁移可能不会自动执行。
集成测试
@Tag("integration") 的测试被 surefire 默认排除；CI 不启动 Spring 上下文，只跑 Mockito 单测与前端门禁。需要 Docker／Testcontainers 的验证要在本地显式启用。
Canal / ShardingSphere
两者都不在运行路径里：Canal 客户端依赖在父 POM 中被注释，ShardingSphere 未引入。搜索同步由 scm-search 的索引接口负责，分库分表未启用。
前端迁移
Ant Design 6 仍在部分存量页面；新页面只使用 shadcn/ui。迁移按域推进，不设“一次性重写”的里程碑。
电商层测试
payment、promotion 等模块有单测；member、mall、search 等模块的测试覆盖仍较薄，不能把“有接口”当成“已验证”。
