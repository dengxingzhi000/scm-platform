02

三条关键链路

请求 · 交易 · 证据

一条租户请求

Tenant → SQL
01

解析租户

客户端携带 X-Tenant-Id（或 Tenant-Id、tenantId 查询参数）。

02

进入上下文

TenantFilter 以 HIGHEST_PRECEDENCE + 10 运行，写入 TenantContextHolder；缺失且 scm.tenant.required=true 时抛出 TenantParseException。

03

认证与授权

JWT 校验通过后，ApiAccessControlFilter 按 URL 向 scm-system 查询权限；查询失败即拒绝，不放行。

04

SQL 重写

TenantInterceptor 给 SELECT、UPDATE、DELETE 追加带别名的 tenant_id 谓词；没有 FROM 的语句跳过，不强行失败。

05

异步传播与清理

@Async 使用 tenantAwareTaskExecutor 继承租户；请求结束后在 finally 清理 ThreadLocal。

一次下单与履约

Order → Fulfillment
01

创建订单

scm-order 创建订单，初始状态 PENDING_PAYMENT；状态变更必须经过聚合的 transitionTo()。

02

预占库存

Redis Lua 原子扣减可用量并写预占索引，默认 900 秒；Seata TCC 为订单与库存提供确认／取消分支。

03

支付回调

验签通过后支付单置为已支付；订单进入 PAID，预占确认转为实扣。重复回调按幂等处理。

04

履约推进

拣货 → 打包 → 发货（登记运单与承运商）→ 签收；订单沿 PENDING_SHIP → SHIPPED → IN_TRANSIT → DELIVERED → COMPLETED 前进。

05

取消或超时

释放预占；订单只能从 PENDING_PAYMENT 或 PAID 进入 CANCELLED，终态不可再变。

一条审计写入

Signed · Append-only
01

切面采集

@AuditLog 被共享的 SysAuditLogAspect 拦截，构造审计记录；未标注的方法不产生记录。

02

服务间投递

SysAuditServiceClient 通过 RestClient 发送，转发 X-Tenant-Id 与调用方 JWT。

03

签名

拦截器生成 HMAC-SHA256 头：timestamp + nonce + appId + uri + sortedParams。

04

守卫校验

AuditWriteRequestGuard 只放行 5 分钟窗口内、签名合法的 POST /sys-audit-log；控制器没有删除入口。

05

高风险镜像

风险等级 ≥ 3 的操作镜像到 sys_sensitive_operation_log；没有 userId 时跳过镜像，但不丢主审计记录。

03

数据的两种速度

交易要准 · 分析要快
OLTP / Hot path

交易与热路径

库存承诺在下单瞬间完成，账本仍在 PostgreSQL 里。两条路径分工明确，不互相等待。

  • PostgreSQL 18每服务独立 db_*
  • 分区表ord_order · inv_reservation · sup_purchase_order
  • 分区保留24 个月
  • Redis 8Lua 扣减 · 回补 · 秒杀
  • 库存预占900 秒超时
  • 读写分离默认关闭，需显式启用
OLAP / Cold path

分析与冷路径

报表不反压订单库。事件先进入 Kafka，再落到 ClickHouse 的分层模型里。

  • Kafka（cp-kafka 8.4.0）事件主干
  • ClickHouse 26.10ODS → DWD → DWS → ADS
  • 排序键tenant_id 优先
  • 保留ODS 1y · DWD 2y · DWS/ADS 3y
  • Elasticsearch 9.5.5商品搜索与重建索引
  • MinIO对象存储 · 30 分钟预签名
04

运行约束

代码里成立的值
租户必填
默认开启。缺失租户时拒绝请求；排除路径为 /actuator/** 与 /v3/api-docs/**。
SQL 隔离
SELECT / UPDATE / DELETE 自动追加谓词。可按服务关闭（scm.tenant.sql-isolation=false）；INSERT 由审计字段填充租户。
权限失败
拒绝，而不是放行。URL 权限查询失败会抛 AccessDeniedException，业务接口因此 fail-closed。
审计写入
HMAC-SHA256 + 5 分钟时间窗。只接受内部服务签名；HTTP 层不提供删除，查询只读。
支付回调
未配置即拒绝。微信 v3 校验 5 分钟时钟窗口；支付宝校验 app_id 与 seller_id；金额、渠道必须匹配本地支付单。
库存预占
900 秒。支付确认转实扣；取消或超时释放；过期预占由批量接口回收。
数据保留
审计 2 年 · 登录 1 年 · API 日志 90 天 · 通知 6 个月 · 订单事件 3 年。分区表默认保留 24 个月。
文件访问
30 分钟预签名。文件元数据与对象存储分离；下载地址不长期暴露。
集成测试
默认跳过。带 @Tag("integration") 的测试被 surefire 排除；CI 运行单元测试与前端门禁。
